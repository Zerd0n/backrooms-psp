# Backrooms PSP v0.1.0

This is the first published playable snapshot of the GPT-5.6 PSP experiment.

The build contains Level 0 and Poolrooms, nextbot pursuit on both maps, a custom software raycaster, ambient loops, and distance-based chase audio. It is packaged for direct use in PPSSPP or on a homebrew-enabled PSP.

This project was made to test how capable GPT-5.6 is of helping revive indie game development on the PSP right now. A person directed the work and tested the builds; the model wrote and revised much of the implementation and tooling.

## Install

1. Download and extract `Backrooms-PSP-v0.1.0.zip`.
2. In PPSSPP, open `BACKROOMS3D/EBOOT.PBP`.
3. On a real PSP, copy `BACKROOMS3D` to `/PSP/GAME/`.

# Backrooms PSP v0.1.0 на русском

Это первая опубликованная рабочая версия эксперимента с GPT-5.6 и разработкой для PSP.

В сборке есть Level 0 и Poolrooms, погоня некстбота на обеих картах, собственный программный raycaster, фоновый эмбиент и музыка погони с громкостью по расстоянию. Архив можно сразу запустить в PPSSPP или скопировать на PSP с поддержкой homebrew.

Проект сделан, чтобы проверить, насколько GPT-5.6 сейчас способна помочь возродить инди-геймдев на PSP. Человек руководил работой и тестировал сборки, а модель написала и переработала значительную часть кода и инструментов.

## Установка

1. Скачайте и распакуйте `Backrooms-PSP-v0.1.0.zip`.
2. В PPSSPP откройте `BACKROOMS3D/EBOOT.PBP`.
3. На настоящей PSP скопируйте папку `BACKROOMS3D` в `/PSP/GAME/`.
