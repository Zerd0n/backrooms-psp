# Backrooms PSP

Небольшая хоррор-игра для PSP, действие которой начинается в Level 0 и продолжается в Poolrooms. Игроку нужно включить три реле, открыть выход и не попасться преследователю.

Эта версия написана заново на C99 для PSPSDK. Прежний код больше не используется. Текстуры, оформление меню PSP, звук и спрайт некстбота сохранены, но сама игра теперь работает на новом 3D-рендерере и новой логике уровней.

## Что изменилось

Появились покачивание камеры при ходьбе, чекпойнт после первого уровня, главное меню, пауза, настройки чувствительности, яркости и громкости, карта изученных комнат, бег с выносливостью и отдельный режим исследования без преследователя.

Некстбот строит маршрут по карте, а музыка погони становится громче, когда он приближается. В Poolrooms есть вода, которая замедляет движение. Игра сохраняет настройки и открытый чекпойнт рядом с `EBOOT.PBP`.

## Запуск

Готовая версия лежит в [dist/BACKROOMS3D](/Users/zerdonov/Documents/Backrooms_PSP/dist/BACKROOMS3D). Команда `python3 tools/project.py build` также создаёт `release/Backrooms-PSP-Rebuilt-v2.0.zip` для распространения.

В PPSSPP откройте `BACKROOMS3D/EBOOT.PBP`. Для PSP скопируйте всю папку `BACKROOMS3D` в `PSP/GAME/` на карту памяти. Папка `assets` должна остаться рядом с `EBOOT.PBP`, иначе не будет звука.

Я тестировал игру в PPSSPP 1.20.4. На реальной PSP показатели FPS могут отличаться: свою консоль я не смог проверить из-за поломки. Поэтому счётчик около 60 FPS в эмуляторе не стоит принимать за замер на железе.

## Управление

| Кнопка | Действие |
| --- | --- |
| Стик или крестовина вверх/вниз | Идти вперёд или назад |
| Стик или крестовина влево/вправо | Поворачивать |
| L / R | Шагать в сторону |
| X, удерживать | Бежать |
| Square | Включить реле или открыть выход |
| Triangle | Открыть карту исследованных мест |
| Start | Пауза |
| Circle | Назад в меню |

На каждом уровне нужно включить три реле. Когда все они активны, дверь у выхода открывается. Level 0 ведёт в Poolrooms, после которого начинается финал.

## Сборка

Нужны Python 3, Docker Desktop с запущенным движком и около 2 ГБ свободного места. Скрипт использует зафиксированный образ PSPDEV и не требует пакетов из `pip`.

```sh
git clone https://github.com/Zerd0n/backrooms-psp.git
cd backrooms-psp
python3 tools/project.py build
```

Команда запускает тесты логики и сохранений, собирает `EBOOT.PBP`, проверяет пакет и создаёт ZIP в `release`. Проверки сохраняются в `logs`.

Для проверки уже собранной версии:

```sh
python3 tools/project.py verify
```

Чтобы поставить игру на подключённую карту памяти:

```sh
python3 tools/project.py install /Volumes/PSP
```

Установщик сохраняет предыдущую папку игры как `BACKROOMS3D.backup.<дата>`. Для возврата используйте:

```sh
python3 tools/project.py restore /Volumes/PSP BACKROOMS3D.backup.<дата>
```
