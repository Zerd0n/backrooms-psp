# Кадры PPSSPP 1.20.4

Сняты из отдельной тестовой сборки с тем же игровым рендерером. Кадр 0090 — меню; 0210 — Level 0; 0330 — стена вблизи; 0450 — карта; 0570 — пауза; 0690 — настройки; 0810 и 0930 — Poolrooms; 1050 — сохранённый некстбот; 1170 — поражение; 1290 — финал.

Захват использует GE-копирование framebuffer в RAM и сохранение PPM; PNG получены только преобразованием формата. Сценарий принудительно устанавливает тестовые состояния и не является прохождением человеком. Лог с частотой кадров находится рядом.
